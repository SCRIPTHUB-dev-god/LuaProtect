UI BUG HUNT REPORT + TUTORIAL

Cara jadi Bug Hunter: 1. Buka DevTools F12, 2. Cek Console merah, 3. Cek Elements, 4. Cek Network untuk icon.png 404, 5. Cek Responsive mobile, 6. Klik semua button, 7. Coba Copy.

  1. [BUG #1] Hamburger kanan tidak ke-klik - Severity: High - Cara Nemu: Buka DevTools > Inspect > Klik hamburger > Cek Console - Repro: 1. Buka halaman 2. Klik hamburger kanan 3. Sidebar tidak terbuka - Fix: .hamburger { width: 44px; height: 44px; z-index: 100; pointer-events: auto; }
  2. [BUG #2] Sidebar 1:3 overflow - Severity: High - Cara Nemu: Buka DevTools > Toggle device toolbar > Cek overflow-x - Repro: 1. Buka di mobile 2. Buka sidebar 3. Halaman bisa scroll ke kanan - Fix: .sidebar { box-sizing: border-box; min-width: 280px; max-width: 380px; } body { overflow-x: hidden; }
  3. [BUG #3] icon.png 404 - Severity: Medium - Cara Nemu: Buka DevTools > Network > Cari icon.png > Cek status 404 - Repro: 1. Hapus icon.png 2. Reload 3. Alt text muncul dan title geser - Fix: onerror="this.style.display='none'" + fallback div icon LP.
  4. [BUG #4] Tab tidak pindah - Severity: High - Cara Nemu: Buka DevTools > Elements > Klik tab > Cek class active - Repro: 1. Klik Obfuscator 2. Klik Information 3. Panel tidak berubah - Fix: querySelectorAll tab, remove active semua, add active ke yang diklik.
  5. [BUG #5] Copy button tidak copy - Severity: Medium - Cara Nemu: Buka DevTools > Console > Klik Copy > Cek error clipboard - Repro: 1. Klik Copy Output 2. Paste 3. Tidak ada teks - Fix: fallback document.execCommand('copy') + textarea sementara.
  6. [BUG #6] Lucide icon tidak muncul - Severity: Medium - Cara Nemu: Buka DevTools > Elements > Cek tag i[data-lucide] belum diganti svg - Repro: 1. Reload 2. Cek ikon 3. Ikon kosong - Fix: panggil lucide.createIcons() di DOMContentLoaded + setelah tab switch.
  7. [BUG #7] Textarea / output tidak scroll - Severity: Medium - Cara Nemu: Buka DevTools > Inspect > Klik textarea > Cek overflow - Repro: 1. Paste kode panjang 2. Scroll 3. Isi terpotong - Fix: textarea, .output-box { overflow: auto; min-height: 180px; resize: vertical; }
  8. [BUG #8] Header title kiri ketutup hamburger kanan - Severity: Medium - Cara Nemu: Buka DevTools > Toggle device toolbar 390px > Cek title - Repro: 1. Buka di layar kecil 2. Cek judul 3. Judul terpotong hamburger - Fix: .topbar { display: flex; justify-content: space-between; } .brand { flex: 1; } .hamburger { flex-shrink: 0; }
