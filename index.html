Information & Features

Aetheria engine provides military-grade source preparation:

  • String Encryption No VM: Encrypts strings using custom XOR + Base91 keys per string.
  • Env Logger Proxy: Optional proxy wrapper for `_G` to monitor calls, gets, and sets.
  • Control Flow Flattening: Flattens execution states to prevent static reading.
  • Padding Inflation: Injects random `_pad` variables to disrupt signatures.
